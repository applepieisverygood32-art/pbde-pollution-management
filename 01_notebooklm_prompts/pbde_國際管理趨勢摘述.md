# PBDE 國際管理趨勢摘述 Prompt

## 適用目的

用於 NotebookLM 摘述 PBDE（多溴二苯醚）國際污染管理制度、污染特性、環境介質及耕地污染管理相關內容。

---

## 使用方式

1. 將政府報告、學術文獻或技術資料匯入 NotebookLM
2. 複製下列 Prompt
3. 貼入 NotebookLM 對話框
4. 依需求調整國家、制度或分析重點

---

## Prompt

請整理資料中「多溴二苯醚（PBDE）」於國際間之污染管理趨勢與制度發展，重點聚焦於「土壤、農地、灌溉系統、底泥及環境管理制度」相關內容，並以政府技術報告可引用之制度描述方式整理。

請重點摘述下列內容：

1. 國際間關注 PBDE 之主要原因與污染特性
2. PBDE 於國際間之管理方向與政策發展趨勢
3. 是否納入持久性有機污染物（POPs）管理架構
4. 各國針對 PBDE 之土壤、底泥、水體或廢棄物管理方式
5. 是否涉及農地、灌溉渠道、污泥施用或食品鏈風險管理
6. 國際間常見之調查方式、監測介質及風險評估方向
7. 目前制度推動限制、資料缺口及管理困難
8. 國際管理趨勢綜整與制度發展方向

請優先整理：
- 美國
- 歐盟
- 日本
- 加拿大
- 澳洲

若資料中有制度名稱、法規名稱、技術指引或正式管理文件名稱，請一併整理。

請避免：
- 過度簡化
- 自行推論未提及內容
- 將學術研究直接解讀為正式制度

若資料不足，請明確標示「資料不足」。
