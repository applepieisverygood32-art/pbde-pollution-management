# PBDE 污染特性與國際關注原因 Prompt

## 適用目的

用於 NotebookLM 摘述 PBDE（多溴二苯醚）污染特性、POPs 管理概念、污染來源及國際風險關注方向等內容。

## 使用方式

1. 將政府報告、技術文件或學術資料匯入 NotebookLM
2. 複製下列 Prompt
3. 貼入 NotebookLM 對話框
4. 取得摘述結果後，再交由 GPT 進行制度整理與報告撰寫

---

## Prompt

請整理資料中「多溴二苯醚（PBDE）」之污染特性與國際間關注原因，重點摘述：

1. PBDE 之主要用途與歷史使用背景
2. 為何被列為國際關注污染物
3. 持久性、生物累積性、長距離傳輸等特性
4. 與 POPs 管理概念之關聯
5. 常見污染來源與排放途徑
6. 為何可能造成環境與食物鏈風險
7. 國際間目前對 PBDE 的主要風險關注方向

請注意：

1. 僅能依據資料庫內容摘述，不得自行補充不存在內容。
2. 請以敘述方式整理，不使用表格。
3. 優先保留正式制度、政策或技術報告用語。
4. 若不同資料有不同描述，請保留原始差異。
