# PBDE 國際管理趨勢綜整 Prompt

## 適用目的

用於 NotebookLM 綜整前述 PBDE（多溴二苯醚）國際管理資料，分析國際間共同管理方向、制度發展脈絡及對農地污染管理之可能啟示。

本 Prompt 建議於前述各批次資料整理完成後再使用。

---

## Prompt

國際管理趨勢綜整

這批為最後統整分析使用。

因為本批內容係建立於前述各批次：

- PBDE 基本污染特性
- 國際管制趨勢與政策方向
- 各國管理制度
- 環境流布與介質特性
- 農地污染風險關聯

等資料基礎上。

請綜整前述 PBDE 國際管理資料，整理國際間 PBDE 管理趨勢共同方向，重點包含：

1. 國際管理方向共同性
2. 從污染整治轉向預防管理之趨勢
3. 與 POPs 或新興污染物管理之共同特性
4. 環境監測制度發展方向
5. 對農地污染管理可能之啟示
6. 對污染源管理與長期監測之重視方向

請避免重複描述，以制度分析與政策發展脈絡為主，不使用表格。

請避免：
- 重複前述各批次已詳細說明內容
- 單純條列式摘要
- 過度推論制度效果
- 將學術研究直接解讀為正式政策

請以：
「制度發展趨勢」
「共同管理方向」
「長期管理思維」

作為主要整理方向。

若資料不足，請明確標示「資料不足」。
