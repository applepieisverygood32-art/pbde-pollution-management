# PBDE 環境流布調查與環境介質監測 Prompt

## 適用目的

用於整理我國（台灣）PBDEs 之環境流布調查、環境介質監測及污染分布特性，作為期中書面報告「國內管理現況與資料盤點」及「耕地污染風險與管理關聯性」章節素材。

---

## Prompt

請依據資料庫內容，整理我國（台灣）目前 PBDEs 之環境流布調查與環境介質監測情形。

請重點摘述：

1. 我國歷年 PBDEs 環境流布調查方向
2. 曾調查之環境介質種類，包括：
   - 水體
   - 底泥
   - 土壤
   - 大氣
   - 生物體
   - 灰塵
   - 生物污泥
3. 主要調查區域或高風險區域
4. 是否曾調查：
   - 工業區
   - 焚化爐
   - 電子廢棄物回收場
   - 河川底泥
   - 農業區域
5. 我國目前 PBDEs 主要環境分布特性
6. 各類介質中 PBDEs 累積或殘留特性

請注意：

1. 僅能依據資料庫內容摘述。
2. 不得補充資料庫外資訊。
3. 不使用表格。
4. 優先保留調查名稱與正式技術用語。
5. 請保留與底泥、土壤及農業環境有關內容。

若資料未提及，請明確標示「資料未提及」。
