# PBDE 國際管理趨勢演進圖卡素材 Prompt

## 適用目的

用於 NotebookLM 整理 PBDE（多溴二苯醚）國際管理制度演進脈絡，作為後續製作：

- 國際管理趨勢演進圖
- 制度演進時間軸
- 政策發展圖卡
- 簡報視覺化架構

等內容之素材。

本 Prompt 重點為：
「制度演進脈絡」
而非單純文獻摘要。

---

## Prompt

請依據資料庫內容，整理 PBDE 國際管理趨勢之制度演進脈絡，作為製作「國際 PBDE 管理趨勢演進示意圖」之素材。

請重點摘述：

1. PBDE 早期主要用途與大量使用背景
2. 國際間開始關注 PBDE 污染與健康風險之原因
3. PBDE 被納入 POPs 管理之發展過程
4. 《斯德哥爾摩公約》列管 PBDEs 之重要內容
5. 國際間由單一化學物質禁限用，逐步轉向：
   - 類群式管理
   - 預防性管理
   - 生命週期管理
   - 循環經濟管理
6. 各國逐步重視：
   - 電子廢棄物
   - 廢棄物回收
   - 生物污泥
   - 底泥
   - 土壤
   - 食物鏈
   - 農業環境風險

   等問題之制度背景
7. 國際管理趨勢目前共同發展方向

請注意：

1. 請以「制度演進脈絡」方式整理。
2. 不要使用表格。
3. 請盡量保留：
   - 制度名稱
   - 法規名稱
   - 管理概念
   - 關鍵政策名詞
4. 不得補充資料庫外資訊。
5. 請特別標示適合作為圖卡關鍵字之短句。

請避免：
- 單純條列摘要
- 過度簡化制度背景
- 將學術研究直接解讀為正式政策
- 自行推論國際管理方向
- 使用口號式描述

請特別強調：
- 管理制度如何逐步演進
- 國際風險認知如何改變
- 管理範圍如何由產品逐步擴大至環境介質與循環體系
