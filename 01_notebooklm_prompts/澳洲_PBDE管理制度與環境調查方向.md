# 澳洲 PBDE 管理制度與環境調查方向 Prompt

## 適用目的

用於 NotebookLM 整理澳洲 PBDE（多溴二苯醚）管理制度、化學物質與 POPs 管理架構、環境介質監測及風險管理方向，作為國際管理趨勢盤點與制度比較分析之基礎資料。

---

## Prompt

請整理澳洲 PBDE 管理制度與環境調查方向，重點摘述：

1. 澳洲 PBDE 管理法規與制度
2. 化學物質或 POPs 管理架構
3. 環境介質監測方向
4. 是否涉及底泥、土壤、水體或農地調查
5. 是否關注食物鏈、生態或長期環境累積風險
6. 是否建立風險評估或長期監測制度
7. 澳洲目前對 PBDE 管理之發展方向

請以敘述方式整理，不使用表格。

請避免：
- 將學術研究直接視為正式制度
- 自行推論澳洲政府未正式提出之政策方向
- 過度簡化化學物質管理架構
- 將單一案例視為全國性管理模式

若資料不足，請明確標示「資料不足」。

請盡量保留：
- 法規名稱
- 制度名稱
- 官方政策用語
- POPs 管理架構名稱
- 澳洲政府環境監測或風險評估計畫名稱
