# 國內管理現況 Prompt

本資料夾用於整理：

我國（台灣）污染物管理制度、環境監測、環境流布、法規列管及風險管理相關 NotebookLM 摘述 Prompt。

- 國內法規制度
- 列管制度
- 環境流布調查
- 環境監測
- 污染來源分析
- 環境傳輸途徑
- 人體暴露研究
- 生態風險研究

# 常見主題

- 毒性化學物質管理
- 環境介質監測
- 底泥調查

- 電子廢棄物
- 生物污泥

# 使用原則

1. 僅能依據資料庫內容摘述。
2. 優先保留正式法規與技術用語。
3. 不得自行推論制度方向。
4. 優先保留與農地、底泥及環境介質相關內容。
