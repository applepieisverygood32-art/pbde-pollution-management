# PBDE 我國管理制度與環境調查發展歷程 Prompt

## 適用目的

用於整理我國（台灣）PBDEs 管理制度、環境調查、監測作業及風險管理之發展歷程，作為：

- 我國 PBDE 管理制度發展歷程圖
- 環境調查時間軸
- 制度演進流程圖
- 簡報圖卡
- 期中報告圖示素材

之基礎資料。

本 Prompt 以：

「流程圖與制度演進示意圖素材」

為主要輸出方向。

---

## Prompt

請依據資料庫內容，整理我國（台灣）PBDEs 管理制度、環境調查及風險管理之發展歷程，作為「我國 PBDE 管理制度與環境調查發展歷程示意圖」製圖資料。

請重點摘述：

1. 我國 PBDEs 管理制度發展的重要時間點
2. 重要法規或列管制度建立時間
3. 是否配合《斯德哥爾摩公約》推動管理
4. 歷年重要環境流布調查或監測計畫
5. 是否曾發生重要污染事件或高污染農地案例
6. 是否開始導入：
   - 農地風險評估
   - 底泥調查
   - 人體暴露研究
   - 綠色整治
   - 預防性管理
7. 我國目前 PBDE 管理方向之演變趨勢

請特別注意：

1. 請盡量保留年份或時間順序。
2. 請以條列方式整理。
3. 不需要長篇說明。
4. 僅能依據資料庫內容摘述。
5. 不得補充資料庫外資訊。
6. 每一項內容請盡量簡短，方便後續轉製流程圖。

請優先保留：

- 年份
- 制度名稱
- 法規名稱
- 調查計畫名稱
- 技術名詞
- 管理方向關鍵字

請避免：

- 長篇制度分析
- 學術討論
- 毒理學內容
- 自行推論制度意義
