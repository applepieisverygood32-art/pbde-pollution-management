# PBDE 主要國家管理制度比較表素材 Prompt

## 適用目的

用於 NotebookLM 整理美國、歐盟、日本、加拿大及澳洲之 PBDE（多溴二苯醚）管理制度重點，作為後續製作：

- 主要國家及區域 PBDE 管理制度重點比較表
- 國際制度比較圖表
- 報告內制度比較段落
- 簡報比較表素材

之基礎資料。

---

## Prompt

請依據資料庫內容，整理美國、歐盟、日本、加拿大及澳洲之 PBDE 管理制度重點，作為製作「主要國家及區域 PBDE 管理制度重點比較表」之素材。

請針對每一國家或區域，分別摘述：

1. 主要管理法規或制度名稱
2. PBDE 主要管理方向
3. 是否涉及：
   - 禁限用管理
   - 產品管理
   - 廢棄物管理
   - 循環經濟
   - 生命週期管理
4. 環境監測或風險評估重點
5. 是否涉及：
   - 土壤
   - 底泥
   - 生物污泥
   - 食物鏈
   - 農業環境

   等風險議題
6. 各國最具代表性之管理特色

請注意：

1. 每個國家請控制於：
   - 5至8點重點
   - 每點盡量簡潔
2. 不要使用表格。
3. 不得補充資料庫外資訊。
4. 請保留制度名稱與正式政策用語。
5. 請特別整理適合放入比較表中的短句。

請避免：
- 自行補充資料庫外制度內容
- 將學術研究直接視為正式制度
- 將單一案例視為國家整體管理方向
- 使用過度籠統描述，例如「加強管理」、「持續關注」
- 未區分正式制度、監測研究與政策趨勢

請輸出時優先整理成「可直接轉換為比較表欄位」的短句。
