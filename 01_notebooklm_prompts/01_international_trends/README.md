# 國際管理趨勢分析 Prompt

本資料夾用於整理：

PBDE、PFAS 及其他污染物之國際管理制度、政策發展、國家比較及管理趨勢相關 NotebookLM 摘述 Prompt。

---

# 主要用途

- 國際管理趨勢盤點
- 國家制度分析
- 國際法規整理
- 管理方向比較
- 制度演進分析
- 類群式管理
- 生命周期管理
- 預防性管理

---

# 常見主題

- 美國管理制度
- 加拿大管理制度
- 日本管理制度
- 歐盟管理制度
- 澳洲管理制度
- Stockholm Convention
- REACH Regulation
- POPs Regulation

---

# 使用原則

1. 優先保留正式制度名稱。
2. 不得補充資料庫外資訊。
3. 避免過度學術化。
4. 優先整理制度演進與政策方向。
