# PBDE 人體暴露與生態風險研究 Prompt

## 適用目的

用於整理我國（台灣）PBDEs 人體暴露、生態風險、食物鏈累積及高暴露族群相關研究內容，作為期中書面報告「耕地污染風險與管理關聯性綜述」章節素材。

---

## Prompt

請依據資料庫內容，整理我國（台灣）目前 PBDEs 人體暴露、生態風險及食物鏈風險相關研究內容。

請重點摘述：

1. 我國是否曾進行：
   - 人體暴露調查
   - 母乳調查
   - 食品調查
   - 魚體或生物體監測
2. 我國目前關注之人體暴露來源
3. PBDEs 是否涉及：
   - 食物鏈累積
   - 生物放大
   - 生態毒性
   - 人體健康風險
4. 我國目前對敏感族群或高暴露族群之調查情形
5. 我國目前對 PBDEs 生態風險之主要研究方向

請注意：

1. 僅能依據資料庫內容摘述。
2. 不得補充資料庫外資訊。
3. 不使用表格。
4. 優先保留正式調查名稱與技術用語。

若資料未提及，請明確標示「資料未提及」。
