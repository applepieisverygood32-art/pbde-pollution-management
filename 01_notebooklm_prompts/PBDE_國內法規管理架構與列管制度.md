# PBDE 國內法規管理架構與列管制度 Prompt

## 適用目的

用於整理我國（台灣）目前針對 PBDEs 之法規管理架構、列管制度、禁限用管理及制度發展方向，作為期中書面報告「國內管理現況與資料盤點」章節素材。

---

## Prompt

請依據資料庫內容，整理我國（台灣）目前針對 PBDEs 之法規管理架構與列管制度。

請重點摘述：

1. 我國目前 PBDEs 管理涉及哪些法規或制度
2. 是否已配合《斯德哥爾摩公約》推動相關管理
3. PBDEs 是否已列為毒性或關注化學物質
4. 我國目前對 PBDEs 之禁限用、輸入、製造或使用管理情形
5. 是否涉及電子電器、廢棄物或資源回收相關管理
6. 我國目前 PBDEs 管理制度發展方向

請注意：

1. 僅能依據資料庫內容摘述。
2. 不得自行補充資料庫外資訊。
3. 不使用表格。
4. 請保留正式法規名稱與制度名稱。
5. 優先保留正式政策或技術報告用語。

若資料未提及，請明確標示「資料未提及」。
