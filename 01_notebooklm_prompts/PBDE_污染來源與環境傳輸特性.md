# PBDE 污染來源與環境傳輸特性 Prompt

## 適用目的

用於整理我國（台灣）PBDEs 之主要污染來源、排放途徑、環境宿命及污染傳輸特性，作為期中書面報告「國內管理現況與資料盤點」及「耕地污染風險與管理關聯性綜述」章節素材。

## Prompt

請依據資料庫內容，整理我國（台灣）PBDEs 之主要污染來源、排放途徑及環境傳輸特性。

請重點摘述：

1. 我國目前認定或關注之 PBDEs 主要污染來源
2. 是否涉及：
   - 電子廢棄物
   - 廢棄物回收
   - 焚化處理
   - 工業製程
   - 大氣排放
   - 污水處理
   - 生物污泥
3. PBDEs 如何進入水體、底泥、土壤或農業環境
4. 是否提及：
   - 大氣沉降
   - 底泥累積
   - 灌溉渠道
   - 食物鏈傳輸
   - 作物吸收
5. 我國目前對 PBDEs 環境宿命與傳輸途徑之調查或研究方向

請注意：

1. 僅能依據資料庫內容摘述。
2. 不得自行補充資料庫外資訊。
3. 不使用表格。
4. 優先保留正式技術用語與研究描述。

若資料未提及，請明確標示「資料未提及」。
