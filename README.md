# PBDE 污染管理 AI 協作模板庫

本資料庫用於整理 PBDE（多溴二苯醚）污染管理相關之 AI 協作 Prompt 模板，供報告撰寫、資料摘述、簡報生成及同事參考使用。

本資料庫以實際工作需求為導向設計，不需要程式背景即可使用。

---

## 使用方式

1. 依照工作需求，進入對應資料夾。
2. 開啟需要的 Prompt 檔案。
3. 複製 Prompt 內容。
4. 將主題、國家、章節名稱或資料內容替換成自己的需求。
5. AI 產出後，仍須由承辦人確認資料來源、邏輯與文字是否適合放入正式報告。

---

## 預計資料夾架構

### 01_notebooklm_prompts

用於 NotebookLM 資料摘述與文獻整理。

適用情境：
- 國際管理趨勢摘述
- 國內管理現況盤點
- 政府報告摘要
- 文獻重點整理
- AI 產出內容檢查

### 02_gpt_prompts

用於 GPT 協助報告撰寫與文字整理。

適用情境：
- 期中報告段落撰寫
- 成果報告段落撰寫
- 管理可行性評估
- 綜合分析
- 委員意見回覆

### 03_slide_prompts

用於 Gemini 或其他 AI 工具生成簡報。

適用情境：
- 政策型簡報生成
- 圖卡式簡報
- 簡報頁面重製
- 逐頁演講稿撰寫

### 04_examples

用於放置實際成功案例，供同事參考。

---

## 使用注意事項

1. AI 產出內容不可直接放入正式報告。
2. 制度、法規、數據及案例內容應回查原始資料。
3. 若資料來源不足，應標示「資料不足」，不可強行推論。
4. 涉及污染來源、風險判定或政策建議時，文字應保持審慎。
5. Prompt 可依實際任務調整，不必完全照抄。

---

## 維護原則

本資料庫會依實際使用經驗持續更新。  
若發現某個 Prompt 產出品質較好，可保留為範本；若產出品質不穩定，應修正後再使用。
